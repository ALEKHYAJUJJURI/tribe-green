# Tribe Green – Project Handover

## 1. Project Overview

Tribe Green is a corporate gifting catalogue and enquiry management system developed as part of the V Green Media practical assignment.

The project includes:
- Responsive website.
- Android mobile application.
- Admin dashboard for enquiry management.
- Shared backend API and MongoDB database.

## 4. Technology Stack

- Website: React, Vite, TypeScript, Tailwind CSS.
- Mobile App: React Native, Expo, TypeScript.
- Backend: Node.js, Express.js.
- Database: MongoDB.
- API Communication: REST APIs.

## 5. Implemented Features

### Website
- Product catalogue.
- Category, occasion and budget filters.
- Product details.
- Enquiry submission.

### Android Application
- Product catalogue.
- Product details.
- Product enquiry submission.
- Backend API integration.

### Admin Dashboard
- Admin authentication.
- Enquiry listing and management.
- Enquiry status updates.
- CSV export.
- Admin logout.

## 6. Backend and Database

The website and Android application use the same deployed backend API and MongoDB database.

The backend handles product data, enquiry submissions, admin authentication, and enquiry management.
